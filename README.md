# 🚀 OrbitTask - Full-Stack Task Management System

**OrbitTask** هو نظام متكامل لإدارة المشاريع وتوزيع المهام بين أعضاء الفريق بأسلوب صايع ومودرن. تم بناء الأبليكيشن باستخدام الـ **MERN Stack** مع دعم كامل للـ Drag & Drop والـ Dark/Light Mode.

---

## ✨ المميزات الرئيسية (Features)

* 🔐 **نظام صلاحيات محكم (Full Authentication):** تسجيل مستخدم جديد وتأمين الحسابات باستخدام `JWT` وتشفير الباسوردات بـ `bcrypt`.
* 📊 **لوحة تحكم ذكية (Dashboard):** عرض إحصائيات المشاريع، عدد المهام، ونسبة الإنجاز مع إمكانية إنشاء مشاريع جديدة فوراً.
* 📋 **لوحة كانبان تفاعلية (Kanban Board):** تنظيم الشغل في أعمدة (To Do, In Progress, Done) مع ميزة الـ **Drag & Drop** لنقل المهام بسلاسة.
* 👥 **إدارة الفريق (Team Collaboration):** إمكانية إضافة أعضاء للمشروع عن طريق الإيميل، وتعيين المهام لشخص محدد (`Assignee`).
* 💬 **نظام تعليقات حيوّي (Comments System):** مناقشة تفاصيل المهام وكتابة التعليقات داخل كل كارت بشكل منفصل.
* 🛠️ **التحكم الكامل (Full CRUD):** إمكانية تعديل ومسح المشاريع، الأعمدة، والمهام بسهولة مع تأمين كامل للـ Routes.
* 🌓 **ثنائية المظهر (Dark / Light Mode):** دعم كامل لتبديل المظهر بأعلى إتقان مع الحفاظ على الهوية البصرية للأبليكيشن (اللمسة الحمراء والروز جولد).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

**الباك إند (Backend):**
* Node.js & Express.js
* MongoDB & Mongoose (Database)
* JSON Web Tokens (JWT) & BcryptJS (Security)

**الفرونت إند (Frontend):**
* React.js (JSX)
* Tailwind CSS
* React Router DOM (Routing)
* Framer Motion (Animations)
* Axios (API Requests)
